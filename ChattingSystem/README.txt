CHAT SYSTEM - BYTE XL / NIMBUS / ECLIPSE

TECHNOLOGIES:
JSP, Servlet, AJAX, JDBC, MySQL, HTML, CSS

SETUP:
1. Open database.sql in your Nimbus MySQL workspace.
2. Execute the complete SQL script.
3. Open this project in Eclipse as an Existing Maven Project.
4. Open:
   src/main/java/com/chat/DBConnection.java
5. Replace:
   YOUR_NIMBUS_HOST
   YOUR_NIMBUS_PORT
   YOUR_NIMBUS_USERNAME
   YOUR_NIMBUS_PASSWORD
   with the connection details shown by Nimbus.
6. Make sure the database name is chatting_system.
7. Configure Apache Tomcat 10.1+ in Eclipse.
8. Run the project on server.
9. Open:
   http://localhost:8080/ChattingSystem/login.jsp
